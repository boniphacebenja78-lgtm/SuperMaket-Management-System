# Supermarket Database Management System

# Project Description: 
The Supermarket Database Management System is a database system designed to support the management of supermarket operations. The system manages products, categories, inventory, suppliers, purchases, sales, customers, discounts, loyalty cards, employees, and inventory movements.
The system is designed to improve the organization and management of supermarket data while maintaining data integrity, security, and efficient access to information.
